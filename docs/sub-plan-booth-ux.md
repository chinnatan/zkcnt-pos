# ปรับ UX/UI หน้าบูธ — ปฏิทิน, ตัวเลือกวันที่ พ.ศ./ค.ศ., และจัดการบูธให้เร็วขึ้น

Branch: `feat/booth-ux` (แตกจาก `feat/booth-mode` เพราะต่อยอดจากงานบูธที่ยังไม่ merge; ทำเมื่อ plan อนุมัติ)

## Business Goals

- เห็นภาพรวมงานที่ไปออกบูธทั้งปีบนปฏิทิน (งานไหนวันไหน ซ้อนกันไหม) และสร้างบูธใหม่ได้โดยเลือกช่วงวันบนปฏิทิน
- เลือกวันที่ด้วย date picker ของแอปเอง แสดง `dd/MM/yyyy` ปี พ.ศ. ตามภาษาไทย / ค.ศ. ตามภาษาอื่น (แก้ปัญหา `<input type="date">` ของเบราว์เซอร์ที่บังคับปีไม่ได้)
- หน้ารายละเอียดบูธไม่เป็นหน้ายาวหน้าเดียวอีกต่อไป: แบ่งหัวข้อชัด เห็นต้นทุนเฉลี่ย/ชิ้นและจุดคุ้มทุนตลอดเวลา และบันทึกด้วยความมั่นใจ (รู้ว่ามีการเปลี่ยนที่ยังไม่บันทึก)
- เลือกสินค้าเข้าบูธเร็วขึ้นเมื่อมีสินค้าเยอะ (กรองเลือกแล้ว/ยังไม่เลือก, เลือก/ล้างทั้งหมด, เตือนเมื่อจำนวนที่นำไปเกินสต๊อก)
- งานที่ไปซ้ำทุกปีตั้งค่าได้ในไม่กี่คลิก (คัดลอกบูธ) และเริ่มขายที่บูธนั้นได้ทันที (ปุ่ม "ใช้ที่ POS")
- ใช้งานบนมือถือได้ลื่น (รายการ → รายละเอียดแบบเข้า-ออกหน้า แทนการเรียงต่อกันยาว)
- ไม่แตะ backend / schema / sync — เป็นงาน frontend ล้วน (ใช้ endpoint เดิมทั้งหมด); เพิ่มได้เฉพาะ dependency ฝั่ง frontend 1 ตัวสำหรับปฏิทิน/date picker (ผ่านการ spike ก่อน)
- วันเริ่มสัปดาห์ของปฏิทินตั้งค่าได้ (ค่าเริ่มต้นอาทิตย์)

## Phase 1: ปฏิทินและ date picker (ชิ้นส่วนใช้ซ้ำ)

### เลือก library (spike สั้น ๆ ก่อนลงมือ)

- [x] ลอง `v-calendar` (v3, Vue 3) ใน scratch: ตรวจว่า (ก) แสดงปี พ.ศ. ในหัวเดือน/ชื่อวันด้วย locale `th-TH-u-ca-buddhist` ได้ (ข) โหมดเลือกช่วงวัน (ค) แถบหลายวันของบูธผ่าน `attributes` (ง) ตั้งวันเริ่มสัปดาห์ได้ (`first-day-of-week`) (จ) ขนาด bundle เพิ่มกี่ KB และธีมเข้ากับ craft style/dark mode โดยไม่ต้องมี `<style>` block
- [x] ถ้า `v-calendar` ไม่ผ่านข้อ (ก) หรือ (ค) ให้ลอง `@fullcalendar/vue3` (daygrid + interaction) สำหรับปฏิทิน และ `@vuepic/vue-datepicker` สำหรับ picker; สรุปตัวเลือกพร้อมเหตุผลใน Appendix ก่อนติดตั้งจริง
- [x] ติดตั้งด้วย `bun add` (ห้าม npm) และ import CSS ของ library ผ่าน `nuxt.config`/`main.css` ปรับสีด้วย CSS variables

### Logic (pure)

- [x] สร้าง `frontend/app/composables/useCalendarPrefs.ts`: มุมมอง (ปฏิทิน/รายการ) และวันเริ่มสัปดาห์ (อาทิตย์/จันทร์/…; ค่าเริ่มต้นอาทิตย์) เก็บใน localStorage ต่อเครื่อง
- [x] สร้าง `frontend/app/lib/booths/calendar.ts`: แปลงบูธ → รูปแบบที่ library ต้องการ, ใช้คีย์ `YYYY-MM-DD` เทียบวัน (ไม่ใช้ `Date` ตรง ๆ กันเขตเวลาเลื่อนวัน), จัดสีตามสถานะ
- [x] เพิ่ม `boothStatus(booth, today)` → `upcoming | ongoing | ended | closed` ใช้ร่วมทั้งปฏิทิน รายการ และ badge (ต่อยอด `isBoothEnded`)

### Components

- [x] `components/booth/BoothCalendar.vue`: ปฏิทินเดือน + ปุ่มก่อนหน้า/ถัดไป/วันนี้ + ตัวเลือก "เริ่มสัปดาห์วัน…", แถบบูธสีตามสถานะ (บูธซ้อนวันกันได้), คลิกแถบ = เลือกบูธ, เลือกช่วงวันว่าง = ส่ง event `create-range` (start,end)
- [x] `components/booth/DateRangePicker.vue`: popover ปฏิทินเลือกวันเริ่ม–จบ (คลิกสองครั้ง) ใช้วันเริ่มสัปดาห์ตาม `useCalendarPrefs`, แสดงค่า `dd/MM/yyyy` ตามภาษา (พ.ศ. ไทย / ค.ศ. อื่น) ผ่าน `formatDateKey`, ปุ่มล้างค่า, ปิดด้วย Esc/คลิกนอก
- [x] ปฏิทินและ picker ทำงานด้วยคีย์บอร์ดได้ (ลูกศรเลื่อนวัน, Enter เลือก) และมี `aria-label`

### เทสต์

- [x] unit test `calendar.ts` + `useCalendarPrefs`: บูธข้ามเดือน/ปี, สถานะบูธตามวันนี้, ค่าเริ่มต้นและการจำค่าวันเริ่มสัปดาห์

### บันทึกผล Phase 1 (spike + ส่วนที่ทำ)

- **ผล spike** (หน้า dev ชั่วคราว + Playwright screenshot, ลบแล้ว):
  - `v-calendar@3.1.2`: เดือน/วันไทยและวันเริ่มสัปดาห์ทำงาน แต่ **ปีขึ้นเป็น ค.ศ.** (ต้องแก้ด้วย slot และรายการเลือกปีใน popover ยังเป็น ค.ศ.) และ attribute แบบ `bar` เป็นแค่เส้นใต้วันที่ — **วาดแถบบูธที่มีชื่อข้ามหลายวัน/หลายสัปดาห์ไม่ได้** → ไม่ใช้ (ถอนแพ็กเกจแล้ว)
  - `@fullcalendar` v6 (`core` + `vue3` + `daygrid` + `interaction`): **หัวเดือนเป็น พ.ศ. อัตโนมัติ** (`ตุลาคม 2569`), แถบมีชื่อข้ามสัปดาห์, หลายงานซ้อนวันได้ไม่ทับ, `firstDay` ตั้งวันเริ่มสัปดาห์ได้, `select` เลือกช่วงวันว่าง → **ใช้สำหรับมุมมองปฏิทิน**
  - (หมายเหตุ: `core`/`vue3` ต้อง major เดียวกับ `daygrid`/`interaction` — v7 ของ core/vue3 ยังไม่มี daygrid/interaction v7 จึงปักที่ `^6.1.21` ทั้งสี่ตัว)
- **date picker เขียนเอง** (`DateRangePicker.vue`, ~100 บรรทัด) แทน library เพราะ library ที่ลองไม่แสดง พ.ศ. และการเขียนเองคุมปี พ.ศ./ค.ศ. ตามภาษาและวันเริ่มสัปดาห์ได้ตรง ๆ ไม่ต้องเพิ่ม dependency ตัวที่สอง
- `lib/booths/calendar.ts` (pure: `addDays`, `boothStatus`, `boothEvents`, `selectionToRange`, `nextRange`, `buildMonthGrid`, `weekdayOrder`), `composables/useCalendarPrefs.ts` (มุมมอง + วันเริ่มสัปดาห์ ต่อเครื่อง), `components/booth/BoothCalendar.vue` (หัวปฏิทินเอง: ก่อนหน้า/วันนี้/ถัดไป/ชื่อเดือน/เลือกวันเริ่มสัปดาห์ + legend สถานะ), `components/booth/DateRangePicker.vue` (popover, ลูกศรเลื่อนโฟกัสวัน/สัปดาห์, Esc ปิด, คลิกนอกปิด)
- เทสต์: `tests/lib/booth-calendar.test.ts` 6 เคส; typecheck ไม่มี error ใหม่
- **ยังไม่ได้ต่อเข้าหน้า** (Phase 2) จึงยังไม่ได้ตรวจ component ด้วยตา; ใช้ผ่าน `<LazyBoothCalendar>` เพื่อไม่ให้ FullCalendar อยู่ใน bundle หลัก

## Phase 2: โครงหน้า `/booths` ใหม่

### มุมมองและการสร้าง

- [x] เพิ่มตัวสลับมุมมอง "ปฏิทิน / รายการ" (จำค่าใน localStorage; ค่าเริ่มต้น: ปฏิทินบนจอใหญ่, รายการบนมือถือ)
- [x] รายการแบ่งกลุ่มตามสถานะ: กำลังจัด / กำลังจะมาถึง / จบแล้ว (กลุ่ม "ปิดแล้ว" พับไว้) พร้อม badge สถานะ
- [x] เปลี่ยนการสร้างเป็น modal เดียว (ชื่อ + `DateRangePicker` + ค่าบูธ) เปิดจากปุ่ม "+ บูธใหม่" หรือจากการลากเลือกวันบนปฏิทิน (กรอกวันที่ให้อัตโนมัติ); ยังดึงสินค้า active ที่มีสต๊อกให้เหมือนเดิม; ไม่ปิดเมื่อคลิก backdrop
- [x] การ์ด/แถบบูธมีเมนูทางลัด: เปิด, ใช้ที่ POS, คัดลอก, ลบ

### มือถือ

- [x] มือถือ: ใช้รูปแบบ list → detail (กดบูธแล้วเข้าหน้ารายละเอียดเต็มจอ มีปุ่มกลับ) แทนการเรียงต่อกัน; ปฏิทินมือถือใช้ปฏิทินเดียวกัน (หัววัน "จ/อ/พ…" แบบย่อ, แถบบูธ + "+N") — **เบี่ยงจากแผน** ไม่ทำแบบจุดสี + รายการด้านล่าง เพราะมุมมองรายการเป็นค่าเริ่มต้นบนมือถืออยู่แล้ว

### บันทึกผล Phase 2

- หน้า `/booths` ใหม่: ตัวสลับ ปฏิทิน/รายการ (จำค่าต่อเครื่อง; ค่าเริ่มต้นปฏิทินบนจอ ≥1024px, รายการบนมือถือ), ปุ่ม "+ บูธใหม่", รายการแบ่งกลุ่ม กำลังจัด / กำลังจะมาถึง / จบแล้ว (ยังไม่ปิด) / ปิดบูธแล้ว (กลุ่มปิดแล้วพับไว้) พร้อม badge สถานะ
- สร้างบูธเป็น modal (`BoothCreateModal`): ชื่อ + `DateRangePicker` + ค่าบูธ; เปิดจากปุ่ม หรือจากการคลิก/ลากวันว่างบนปฏิทิน (กรอกวันที่ให้) ยังดึงสินค้าที่มีสต๊อกเข้าบูธเหมือนเดิม; ไม่ปิดเมื่อคลิก backdrop
- การ์ดบูธมี "ใช้ที่ POS" (ตั้งบูธของเครื่องนี้ แล้วไป `/pos`) และ "ลบ"; ปุ่ม "คัดลอก" อยู่ Phase 5
- มือถือ: รายการ/ปฏิทินถูกแทนด้วยหน้ารายละเอียดเต็มจอเมื่อเลือกบูธ (ปุ่ม "← กลับ"); สลับมุมมองจะออกจากรายละเอียด
- พบจากการตรวจหน้าจริงและแก้แล้ว: popover ของ date picker ถูก modal ตัด → ย้ายเป็น `Teleport` + `fixed` (พลิกขึ้นบนถ้าที่ไม่พอ); หัววันบนมือถือยาวจนล้น → ใช้แบบย่อ (th "จ", en "Mon"); `th` locale ของ FullCalendar ไม่ได้โหลด จึงแสดง "+N" เองแทนข้อความ "more"
- ตรวจด้วย Playwright (build จริง): วัดความกว้างหน้ามือถือ `scrollWidth = clientWidth = 390`, console สะอาด, ปี พ.ศ. ในหัวปฏิทิน/picker/รายการ, วันเริ่มสัปดาห์เปลี่ยนเป็นจันทร์ได้, "ใช้ที่ POS" ตั้งตัวเลือกบน POS สำเร็จ
- ขนาด: chunk ของ FullCalendar ~230 KB (69 KB gzip) โหลดเมื่อเปิดมุมมองปฏิทินเท่านั้น (`<LazyBoothCalendar>`)
- ข้อสังเกตเล็กที่ยังไม่แก้: บนมือถือขอบขวาของตารางปฏิทินชิดขอบการ์ดมากจนเส้นขอบขวาถูกตัดเล็กน้อย; รายละเอียดบูธยังใช้ `<input type="date">` เดิม (เปลี่ยนเป็น `DateRangePicker` ใน Phase 3)
- เทสต์: vitest 72/72, typecheck ไม่มี error ใหม่

## Phase 4: เลือกสินค้าเข้าบูธให้เร็วขึ้น

### ตัวกรองและการเลือกกลุ่ม

- [ ] ชิปกรอง: ทั้งหมด / เลือกแล้ว / ยังไม่เลือก / สต๊อกหมด และช่องค้นหาเดิม

### ข้อสมมติ/การตัดสินใจที่ขอ user ยืนยัน

1. **ใช้ library** (ตามที่ user อนุมัติ) — ผล spike: ใช้ **FullCalendar v6** สำหรับมุมมองปฏิทิน (แสดง พ.ศ. ได้เอง + แถบมีชื่อ) และเขียน date picker เอง (ดูบันทึกผล Phase 1)
2. **วันเริ่มสัปดาห์ตั้งค่าได้** ค่าเริ่มต้นอาทิตย์ — เก็บต่อเครื่องใน localStorage (เหมือนมุมมองปฏิทิน/รายการ และบูธที่เลือกบน POS) เปลี่ยนได้จากเมนูเล็กบนหัวปฏิทิน และมีผลกับ date picker ด้วย; ไม่ทำเป็นค่าระดับร้านเพราะต้องออนไลน์ + สิทธิ์ manager เท่านั้น
3. **ค่าเริ่มต้นมุมมอง**: ปฏิทินบนจอใหญ่ / รายการบนมือถือ (ยืนยันแล้ว)
4. **บูธซ้อนวันกันได้** (ยืนยันแล้ว) — ปฏิทินแสดงหลายแถบไม่ทับกัน ไม่ห้ามสร้าง
5. **"ใช้ที่ POS" ตั้งเฉพาะเครื่องนี้** — บนหน้า POS การเลือกบูธถูกเก็บในเบราว์เซอร์ของเครื่องที่ใช้ (ไม่ซิงก์ข้ามเครื่อง) เพราะแคชเชียร์ต้องสลับบูธเองได้แม้ออฟไลน์; ปุ่มนี้เป็นทางลัดเดียวกับ dropdown บน POS: กดแล้วตั้งบูธนี้ให้ POS ของเครื่องที่กดอยู่ แล้วพาไปหน้า POS ตัวอย่าง: ผู้จัดการกดบน iPad → iPad ขายที่บูธ A, มือถือของพนักงานอีกคนยังเลือกเองบน POS
6. ไม่แก้ backend/schema; การคัดลอกบูธเรียก endpoint เดิม (`POST /booths`, `POST /booth-products`), เปิดบูธอีกครั้งใช้ `PATCH closed_at = ""`
7. **ยังไม่ทำ** (เสนอไว้แต่ตัดออก): อัปโหลดรูปบูธตอน offline (ต้องเพิ่มคิวไฟล์), ลากย้ายแถบบูธบนปฏิทินเพื่อเลื่อนวัน, มุมมองปีทั้งปี, นำเข้า/ส่งออกบูธ
